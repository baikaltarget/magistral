# Правила
Проверь metadata, canonical, robots, sitemap, SSR/SSG HTML, alt, размеры картинок, CLS, JSON-LD, ссылки и редиректы. Не навязывай фиксированные длины title/description. Сохраняй текущий способ сборки и проверяй lint/typecheck/build где возможно.
